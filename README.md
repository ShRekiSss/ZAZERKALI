# 🙇 Поклон Волшебнику — кликер-таймкиллер (MVP)

Мобильный кликер: тапаешь — челик кланяется Великому Волшебнику, копишь «Благосклонность»,
покупаешь апгрейды, читаешь жутко-милые сюжетные фразы. Стиль: Fran Bow × «Зазеркалье».

Полный план — в [ROADMAP.md](ROADMAP.md), идеи — в [IDEAS.md](IDEAS.md).

## Сборка APK (автоматически в облаке)

Каждый пуш в `main` собирает APK через GitHub Actions (образ `barichello/godot-ci:4.6`).
Скачать: **Actions → последний прогон → Artifacts → zazerkali-apk**. Ничего ставить
на компьютер не нужно. Пресет экспорта — `export_presets.cfg`.

## Как запустить (Godot 4.6)

1. Открой Godot → **Import** → выбери папку `wizard-clicker` (файл `project.godot`).
2. Нажми **F5** (Run Project) — игра запустится в окне 720×1280 (портрет).
3. Мышь эмулирует палец (включено в настройках проекта), так что тапай мышкой.

## Что уже работает в каркасе

- Тап по экрану → челик кланяется (анимация Tween) → +Благосклонность
- 6 апгрейдов (сила поклона / авто-доход), цены растут ×1.15–1.20 за уровень
- Автодоход «толпы» тикает сам
- Автосохранение каждые 30 сек, при сворачивании и выходе (`user://save.json`)
- Оффлайн-доход до 8 часов («пока тебя не было, толпа кланялась»)
- 15 сюжетных фраз, показываются по порогам благосклонности

Сейчас всё на цветных прямоугольниках — это нормально, арт подключается на Этапе 3.

## Структура

```
project.godot          — настройки: портрет 720×1280, автозагрузка GameState
scenes/main.tscn       — сцена кликера (2D)
scenes/toon3d.tscn     — 3D-демо: toon shader + зеркало (кнопка в кликере)
scripts/game_state.gd  — вся логика чисел: валюта, апгрейды, сейвы, сюжет
scripts/main.gd        — тапы, анимация поклона, UI
scripts/toon3d.gd      — сборка 3D-демо: свет, персонажи, SubViewport-зеркало
assets/shaders/        — toon.gdshader (cel shading), mirror.gdshader (отражение+дисторшн)
assets/models/         — пак Kenney Fantasy Town Kit (CC0, GLB/FBX/OBJ) + Meshy-персонажи
assets/audio/          — ЗВУКИ: tap.wav, bell.wav, ambient.ogg (см. ниже)
assets/sprites|textures — сюда кладём свои ассеты (латиницей, без пробелов)
```

## Звук

Всё уже в проекте (`assets/audio/`), качать ничего не нужно:
- `theme.wav` — **главная тема**: «Vaanrile — Drowning Into Despair» (выбор автора)
- `cloth1-4.ogg` — шорохи на тап (Kenney, CC0, случайный выбор)
- `coins.ogg` — покупка апгрейда (Kenney, CC0)
- `creak.ogg` — сюжетная фраза (Kenney, CC0)
- Эмбиент-дрон — синтезируется кодом, запасной вариант если theme.wav удалить

**Настройки звука:** кнопка «Настройки звука» в игре → ползунки «Общая громкость /
Музыка / Эффекты» (отдельные аудио-шины, громкость сохраняется в `user://settings.cfg`).

**Правило проекта:** вся логика чисел — только в `game_state.gd`. UI ничего не считает сам.

## Что дальше (по роадмапу)

1. Настроить Android-экспорт и собрать APK: Editor Settings → Export → Android
   (нужны JDK 17 + Android SDK; Godot сам предложит скачать Android Build Templates).
2. Потрогать баланс апгрейдов в `game_state.gd` (константы `UPGRADES`).
3. Арт: паки с itch.io (free, tags: 2d + hand-drawn + dark fantasy/horror), репейнт в Krita/Photopea.
4. Престиж через Зеркало (Этап 4): константа `MIRROR_COST` уже ждёт в `game_state.gd`.
